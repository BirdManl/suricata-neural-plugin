# Нейросетевой плагин для Suricata

Выпускная квалификационная работа: **«Разработка нейросетевого модуля системы обнаружения вторжений Suricata на базе РЕД ОС для повышения точности детекции аномалий в сетевом трафике»**.
Муромский институт (филиал) ВлГУ, направление «Информационная безопасность», 2026.

Плагин работает рядом с [Suricata](https://suricata.io/): читает журнал `eve.json`, превращает метаданные сетевых потоков в числовые признаки и с помощью нейронной сети определяет, похож ли поток на атаку. Он дополняет сигнатурное обнаружение: ловит поведенческие аномалии, для которых нет готовых правил.

## Как это работает

```
Suricata ──> eve.json ──> сбор событий ──> 15 признаков + StandardScaler ──> MLP (ONNX) ──> алерт ──> веб-интерфейс
             (flow)       (tail -F / файл)                                   норма / атака
```

1. Suricata пишет события в `eve.json` (в проекте используются события типа `flow`).
2. Плагин читает файл в режиме слежения (`tail`) или разбирает его целиком (`file`).
3. Из каждого потока вычисляется 15 признаков, они нормализуются сохранённым `StandardScaler`.
4. MLP-модель (формат ONNX, запуск через `onnxruntime`) возвращает вероятность атаки. Если она выше порога, формируется алерт.
5. Алерты и статистика отображаются в веб-интерфейсе на Flask.

## Нейросетевая модель

| Параметр | Значение |
|---|---|
| Архитектура | MLP: Dense 128 → BatchNorm → Dropout 0,3 → Dense 64 → BatchNorm → Dropout 0,2 → Dense 32 → Dense 1 (sigmoid) |
| Фреймворк обучения | TensorFlow / Keras, экспорт в ONNX через `tf2onnx` |
| Датасет | CIC-IDS-Collection, 9 167 581 потоков (21,6 % атаки, 78,4 % норма) |
| Разбиение | 80 % обучение / 20 % тест, стратифицированное |
| Признаки | 15 метрик потока, которые реально присутствуют в `eve.json` |
| Порог | 0,50 (подобран по F1 для класса «атака») |

**Признаки:** `duration`, `fwd_pkts`, `bwd_pkts`, `fwd_bytes`, `bwd_bytes`, `dest_port`, `proto_tcp`, `bytes_per_sec`, `pkts_per_sec`, `bytes_per_pkt`, `fwd_bwd_pkt_ratio`, `fwd_bwd_bytes_ratio`, `fwd_bytes_per_pkt`, `bwd_bytes_per_pkt`, `pkt_asymmetry`.

**Качество на тестовой выборке (1 833 517 потоков):**

| Класс | Precision | Recall | F1 |
|---|---|---|---|
| Норма | 0,94 | 0,96 | 0,95 |
| Атака | 0,83 | 0,79 | 0,81 |

Accuracy 0,92, ROC-AUC 0,929. Подробности в ноутбуках `src/model_training_v2.ipynb` и `src/data_exploration.ipynb`.

## Проверка на лабораторном стенде

Стенд: РЕД ОС с Suricata и плагином, атакующая машина Kali Linux, цель DVWA, изолированная виртуальная сеть. Сценарии атак составлены по OWASP Top 10 и MITRE ATT&CK, инструменты: nmap, Hydra, hping3, sqlmap, gobuster, ffuf, nikto и другие. Suricata и плагин запускались параллельно, сравнивалось число срабатываний.

| Атака | Срабатываний Suricata | Срабатываний плагина |
|---|---|---|
| Сетевая разведка (nmap) | 12 | 71 |
| Брутфорс (Hydra) | 0 | 156 |
| SYN-flood (hping3) | 124 | 20 292 |
| SQL-инъекция (sqlmap) | 89 | 237 |
| Нарушение контроля доступа | 0 | 33 |

Больше срабатываний не значит «лучше»: таблица показывает охват, а не точность. Классическая Suricata остаётся точнее на известных атаках с чёткими сигнатурами, а плагин закрывает поведенческие аномалии. Методика и полный разбор сценариев описаны в ВКР (`docs/`).

## Ограничения

- Модель обучена на CIC-IDS, а не на трафике конкретной сети. По результатам тестов фоновый уровень ложных срабатываний около 15 %, поэтому одиночный алерт с невысокой уверенностью трудно отличить от шума.
- Бинарная классификация: модель говорит «норма / атака», но не определяет тип атаки.
- Используются только метаданные потоков, содержимое пакетов и HTTP-запросов не анализируется.
- Путь к модели и к `eve.json` в `src/app.py` задан в словаре `state`, его нужно поменять под свою систему.

## Запуск

Нужны Python 3.9+ и работающая Suricata, пишущая `eve.json` (пример настройки в `suricataplugin/suricata/etc/suricata.yaml`).

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt

# консольный режим: слежение за журналом Suricata
python3 suricataplugin/src/suricata_nn_plugin.py \
    --eve /var/log/suricata/eve.json --mode tail \
    --model suricataplugin/data/models

# веб-интерфейс, затем открыть http://localhost:5000
python3 suricataplugin/src/app.py
```
